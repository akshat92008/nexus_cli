Write a Python script `src/metrics.py` that parses a CSV file and calculates the 95th percentile of the 'latency' column.

RAW PIPELINE OUTPUT:
<<THINKING>>
I will implement a Python function to calculate the 95th percentile of latency from a CSV file.

<<FILES>>
```python
# filepath: src/metrics.py
# action: CREATE

import pandas as pd

def calculate_95th_percentile(file_path):
    # Load the CSV file into a DataFrame
    df = pd.read_csv(file_path)
    
    # Calculate the 95th percentile of the 'latency' column
    latency_95th_percentile = df['latency'].quantile(0.95)
    
    return latency_95th_percentile
```

RAW PIPELINE OUTPUT:
<<THINKING>>
I will implement an iterative Python function for calculating factorials in `utils/math.py`.

<<FILES>>
```python
# filepath: utils/math.py
# action: CREATE

def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result
```

==================== REGRESSION CASE A3 ====================
PROMPT:
Implement a REST endpoint in `app.py` using Flask that returns the current UTC time in ISO format.

RAW PIPELINE OUTPUT:
<<THINKING>>
I will implement a Flask route at `/api/time` that returns the current UTC time in ISO format.

<<FILES>>
```python
# filepath: app.py
# action: CREATE

from flask import Flask, jsonify
import datetime

app = Flask(__name__)

@app.route('/api/time')
def get_time():
    now = datetime.datetime.utcnow()
    return jsonify({'time': now.isoformat()})

if __name__ == '__main__':
    app.run(debug=True)
```
