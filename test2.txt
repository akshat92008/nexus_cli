What's the difference between a process and a thread?

RAW PIPELINE OUTPUT:
<<THINKING>>
This is an explanation request about concurrency.

<<RESPONSE>>
A process is an instance of a program running on a computer. It has its own memory space, separate from other processes. A thread is a lightweight unit of execution within a process that shares the same memory space as the parent process. Threads are faster to create and destroy than processes because they share resources.

**Key differences:**
1. **Memory Space**: 
   - Process: Separate memory space
   - Thread: Shares memory with parent process

2. **Creation/Destruction Time**:
   - Process: Slower (forking)
   - Thread: Faster (context switching)

3. **Concurrency Level**:
   - Process: Multiple processes can run concurrently
   - Thread: Multiple threads within a single process can run concurrently

4. **Resource Sharing**:
   - Process: No sharing
   - Thread: Shared memory, file descriptors, etc.

5. **Context Switching**:
   - Process: Requires more context switching (forking)
   - Thread: Less context switching (context switch between threads)

6. **Synchronization**:
   - Process: More complex synchronization needed
   - Thread: Easier to synchronize due to shared memory

7. **Use Cases**:
   - Process: Suitable for CPU-bound tasks, separate processes are required
   - Thread: Suitable for I/O-bound tasks, multiple threads can share resources

from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Email, Length

class SignupForm(FlaskForm):
    email = StringField('Email', validators=[DataRequired(), Email()])
    password = PasswordField('Password', validators=[DataRequired(), Length(min=8)])
    submit = SubmitField('Sign Up')
```

import pandas as pd
import json

def csv_to_json(csv_file, json_file):
    # Read the CSV file into a DataFrame
    df = pd.read_csv(csv_file)
    
    # Convert the DataFrame to JSON format
    json_data = df.to_json(orient='records')
    
    # Write the JSON data to a file
    with open(json_file, 'w') as f:
        f.write(json_data)
```
